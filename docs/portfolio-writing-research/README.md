# Portfolio writing research

Date: 2026-06-28

This folder captures the first research pass for adding a writing/blog section to the portfolio. It is not an implementation plan yet. The goal is to record what the reference sites are doing well, what writing patterns are worth borrowing, and what visual/development directions would fit Sher's portfolio revamp without copying anyone directly.

Important direction: the future revamp should move the website toward a light theme. The current dark terminal/pixel site is useful context, but the next version should not stay primarily dark. The research below should be read with that in mind.

## Files

- [01-source-audit.md](01-source-audit.md): what was accessed, what was extracted, and any limitations.
- [02-reference-learnings.md](02-reference-learnings.md): site-by-site observations.
- [03-visual-cues.md](03-visual-cues.md): visual motifs, layout patterns, and uniqueness cues.
- [04-writing-style-notes.md](04-writing-style-notes.md): how people write about themselves, work, projects, and thoughts.
- [05-development-notes.md](05-development-notes.md): implementation-shaping notes for a future build, without building it now.
- [06-content-directions.md](06-content-directions.md): possible original directions for Sher's writing section.

## Research principle

The references should be treated as a vocabulary, not a template. The strongest direction for this portfolio is not "copy Arjun's cards" or "copy Alana's desktop." It is to create a lighter, cleaner, more readable system for Sher's essays, project notes, diagrams, and build logs while keeping the deeper identity: AI systems, research, timelines, agents, and evidence.
